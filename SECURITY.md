# Security policy

## Reporting a problem

Report a security problem privately: on this repository's Security tab, click Report a vulnerability. Do not open a public issue for it.

Say what an attacker can do, and the steps to make it happen.

## Supported versions

Only the latest release gets fixes. To update your copy, see Updating in the README.

## What is in scope

[docs/security.md](docs/security.md) lists what timecapsule protects and what it does not. A way around anything on its Protected list is in scope. Anything on its Not protected list is a known limit, not a bug.
